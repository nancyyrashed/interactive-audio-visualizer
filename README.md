# Interactive Audio Visualizer

## Overview

An interactive music visualization system that generates dynamic visual effects based on audio features extracted from music tracks.

The project demonstrates real-time audio analysis and visualization techniques using web technologies.

## Features

* Real-time audio visualization
* Frequency spectrum analysis
* Interactive visual effects
* Music-responsive animations

## Technologies Used

* JavaScript
* HTML
* CSS
* p5.js

## Skills Demonstrated

* Audio Feature Extraction
* Data Visualization
* Interactive Web Development
* Creative Coding
